## Global Permutation Test for Gene-Level Genetic Variance

Objective

The objective of this project is to determine whether the observed genetic variance (Vg) of genes is significantly lower than expected under a neutral model, consistent with selective constraint on regulatory variation.

We assess this by comparing observed per-gene genetic variance to a permutation-based null distribution generated by randomly reassigning allele frequencies (AFs) from a global pool of observed variants. This null represents the potential regulatory variance a gene could exhibit if allele frequencies were not shaped by selection.

The final output is a gene-level empirical rank statistic quantifying how extreme the observed variance is relative to this null.

⸻

Conceptual Model

Genetic Variance Framework

For each variant i in a gene g, genetic variance is modeled additively as:

V_{g} = \sum_{i \in g} 2 \cdot p_i \cdot (1 - p_i) \cdot \beta_i^2

where:
	•	p_i is the allele frequency,
	•	\beta_i is the predicted regulatory effect size (absolute effect),
	•	variants are assumed independent and additive.

This model captures how both effect size and allele frequency jointly determine contribution to regulatory variance.

⸻

Null Hypothesis and Permutation Strategy

Null Hypothesis

The observed allele frequencies of variants within a gene are exchangeable with allele frequencies from the global pool of observed variants.

Under this hypothesis, any depletion of genetic variance arises purely by chance rather than selective constraint.

Global Permutation Design

To ensure a uniform and unbiased null, we use a single global AF pool:
	•	Constructed from all non-zero allele frequencies observed in gnomAD
	•	Shared across all genes and sources (background, ClinGen, etc.)

Each permutation iteration:
	1.	Randomly assigns AFs from this global pool to all variants (with replacement)
	2.	Recomputes per-gene genetic variance
	3.	Aggregates results at the gene level only

This approach isolates the effect of allele frequency distribution while preserving:
	•	Gene structure
	•	Variant effect sizes
	•	Variant counts per gene

⸻

Output Metric

For each gene, we compute:
	•	Observed Vg
	•	Null distribution of shuffled Vg values
	•	Empirical rank percentile:

\text{rank} = \frac{\#(V_{g}^{\text{shuffled}} > V_{g}^{\text{observed}})}{N_{\text{iterations}}}

Interpretation:
	•	Rank ≈ 0 → observed variance unusually low (constraint)
	•	Rank ≈ 0.5 → consistent with null
	•	Rank ≈ 1 → unusually high variance

⸻

Scope Clarifications (Explicit Assumptions)
	1.	Unified global AF pool
	•	A single AF pool is constructed from all gnomAD-observed variants.
	•	This ensures identical null expectations across all genes and datasets.
	•	No gene-, region-, or source-specific AF stratification is applied.
	2.	Variant-level shuffling
	•	AFs are permuted at the variant level, not the gene level.
	•	Variant effect sizes and gene assignments remain fixed.
	•	Sampling is performed with replacement to avoid depletion artifacts.
	3.	Gene-level aggregation only
	•	Variant-level shuffled data are never stored.
	•	All permutations are immediately reduced to per-gene Vg values for memory efficiency.
	4.	Constraint direction
	•	The test is explicitly one-sided, focused on detecting depletion of variance.
	•	The rank statistic therefore counts shuffled values greater than observed.

⸻

Implementation Plan (High-Level)

Data Flow
	1.	Arrange
	•	Load global AF pool from gnomAD
	•	Load variant datasets (null parquets)
	•	Ensure each variant has:
	•	gene_id
	•	abs_effect
	•	observed af
	2.	Act
	•	Compute observed Vg per gene
	•	For n_iterations:
	•	Sample AFs from global pool
	•	Compute shuffled per-gene Vg
	•	Store results in a gene × iteration structure
	3.	Assert / Output
	•	Compute empirical rank per gene
	•	Output results as a typed, gene-level table
	•	Save as parquet for downstream analysis

⸻

Performance and Engineering Constraints
	•	Polars LazyFrames for all IO and grouping
	•	NumPy for permutation math
	•	Memory-efficient aggregation (no variant-level shuffles stored)
	•	Deterministic reproducibility via fixed RNG seed
	•	Progress logging every 10 iterations
	•	Strict typing using dataclass and TypedDict

⸻

Final Deliverable

A gene-level parquet table containing:
	•	gene_id
	•	observed genetic variance
	•	mean shuffled genetic variance
	•	empirical percentile rank

This table enables:
	•	Genome-wide constraint analyses
	•	Comparison between ClinGen and background gene sets
	•	Integration with downstream statistical or biological interpretation

	•	Uses polars (lazy scan) for IO and initial prep
	•	Uses numpy for inner-loop math and fast per-gene aggregation via np.bincount
	•	Uses dataclasses + TypedDict and strict type hints
	•	Logs progress every 10 iterations
	•	Raises FileExistsError when paths missing and ValueError when AF pool empty
	•	Memory-efficient: no full shuffled variant tables stored; only per-gene aggregated results are kept
	•	Saves result as parquet

from __future__ import annotations
import os
import logging
from dataclasses import dataclass
from typing import TypedDict, Dict, List, Tuple, Any

import numpy as np
import polars as pl

# -----------------------------
# Config & TypedDicts
# -----------------------------

@dataclass
class PermutationConfig:
    n_iterations: int = 100
    seed: int = 42
    af_pool_path: str = "path/to/gnomad_observed.parquet"
    variants_path: str = ""  # used in per-source context if needed
    out_path: str = "permutation_vg_results.parquet"
    log_every: int = 10


class GenePermutationResult(TypedDict):
    gene_id: str
    source: str
    observed_vg: float
    shuffled_mean_vg: float
    rank_percentile: float  # fraction of shuffled > observed
    n_iterations: int


# -----------------------------
# Utility: calculate per-variant vg
# -----------------------------
def _calculate_vg_per_variant(afs: np.ndarray, abs_effects: np.ndarray) -> np.ndarray:
    """
    Pure function: given arrays of allele frequencies and absolute effects,
    return per-variant contribution to genetic variance under additive model:
        vg_i = 2 * p * (1 - p) * beta^2

    Both inputs must be 1-D numpy arrays of the same length.
    """
    if afs.shape != abs_effects.shape:
        raise ValueError("afs and abs_effects must have the same shape")
    # numeric safety: clip afs in (0,1)
    p = np.clip(afs, 0.0, 1.0)
    beta2 = np.square(abs_effects)
    return 2.0 * p * (1.0 - p) * beta2


# -----------------------------
# Load AF pool (gnomad) -> numpy.ndarray
# -----------------------------
def load_af_pool(af_pool_path: str) -> np.ndarray:
    """
    Load gnomAD AF pool from a parquet file (using polars lazy scan).
    Extract all non-zero afs into a numpy array.
    """
    if not os.path.exists(af_pool_path):
        raise FileExistsError(f"AF pool file not found: {af_pool_path}")

    # Use lazy scan for IO as requested
    lf = pl.scan_parquet(af_pool_path).select(pl.col("af"))
    df = lf.filter(pl.col("af").is_not_null()).collect()
    # convert to numpy array
    afs = df["af"].to_numpy()
    # keep only non-zero afs (explicit)
    afs = afs[afs > 0.0]
    if afs.size == 0:
        raise ValueError("AF pool is empty after filtering non-zero afs")
    return afs


# -----------------------------
# Load variants (null table) -> compact numpy-friendly representation
# -----------------------------
def load_variant_table(variants_path: str) -> Tuple[np.ndarray, np.ndarray, np.ndarray]:
    """
    Load a variants parquet that must contain columns:
       - gene_id (string)
       - abs_effect (float)
       - af (float)    # observed AF for the dataset (used to compute observed Vg)
    Returns:
       gene_ids_arr: array of unique gene ids
       gene_idx_per_variant: integer array mapping variant index -> gene index
       abs_effects: float array per variant
       observed_afs: float array per variant
    """
    if not os.path.exists(variants_path):
        raise FileExistsError(f"Variants file not found: {variants_path}")

    # Lazy scan and collect only needed columns
    # This ensures polars does most of IO work lazily, then we load the minimal columns.
    lf = pl.scan_parquet(variants_path).select(["gene_id", "abs_effect", "af"])
    df = lf.collect()

    # validate columns
    for col in ("gene_id", "abs_effect", "af"):
        if col not in df.columns:
            raise ValueError(f"Missing required column '{col}' in {variants_path}")

    # Drop rows with missing abs_effect (can't compute Vg)
    df = df.filter(pl.col("abs_effect").is_not_null())

    gene_ids = df["gene_id"].to_numpy()
    abs_effects = df["abs_effect"].to_numpy().astype(float)
    observed_afs = df["af"].to_numpy().astype(float)

    # Build mapping: gene -> integer index
    unique_genes, gene_inverse_idx = np.unique(gene_ids, return_inverse=True)
    # gene_inverse_idx is the gene index for each variant (0..n_genes-1)
    return unique_genes, gene_inverse_idx, abs_effects, observed_afs


# -----------------------------
# Main permutation engine for one source
# -----------------------------
def run_permutations_for_source(
    source_name: str,
    variants_path: str,
    af_pool: np.ndarray,
    cfg: PermutationConfig
) -> List[GenePermutationResult]:
    """
    For a single source (e.g., 'clingen' or 'background'), run the permutations and
    return a list of GenePermutationResult dictionaries.
    """

    unique_genes, gene_idx_per_variant, abs_effects, observed_afs = load_variant_table(variants_path)
    n_variants = abs_effects.shape[0]
    n_genes = unique_genes.size

    # Observed per-variant vg contributions and observed per-gene Vg
    vg_per_variant_obs = _calculate_vg_per_variant(observed_afs, abs_effects)
    observed_vg_per_gene = np.bincount(gene_idx_per_variant, weights=vg_per_variant_obs, minlength=n_genes)

    # Pre-allocate storage for shuffled Vg sums per gene across iterations in float32 to save memory
    shuffled_vg_accumulator = np.zeros((n_genes, cfg.n_iterations), dtype=np.float64)

    rng = np.random.default_rng(cfg.seed)

    # Warn if AF pool is smaller than variants (not an error because sampling is with replacement),
    # but user requested to "ensure pool is large enough"
    if af_pool.size < max(1000, n_variants // 10):
        logging.warning(
            "AF pool is relatively small (%d). Sampling with replacement is used, "
            "but consider a larger AF pool for better mixing", af_pool.size
        )

    # Iterative permutations
    for it in range(cfg.n_iterations):
        # sample with replacement for all variants
        sampled_afs = rng.choice(af_pool, size=n_variants, replace=True)

        # compute per-variant vg for this iteration
        vg_per_variant_shuffled = _calculate_vg_per_variant(sampled_afs, abs_effects)

        # aggregate per gene via np.bincount (very fast)
        vg_per_gene_shuffled = np.bincount(gene_idx_per_variant, weights=vg_per_variant_shuffled, minlength=n_genes)

        # store into accumulator (column = iteration)
        shuffled_vg_accumulator[:, it] = vg_per_gene_shuffled

        # logging progress
        if (it + 1) % cfg.log_every == 0 or (it + 1) == cfg.n_iterations:
            logging.info("Source=%s iteration %d/%d", source_name, it + 1, cfg.n_iterations)

    # compute per-gene statistics: mean shuffled vg and percentile rank (fraction of shuffled > observed)
    shuffled_mean_vg = np.mean(shuffled_vg_accumulator, axis=1)
    # For rank calculation: count how many shuffled values are strictly greater than observed
    counts_greater = np.sum(shuffled_vg_accumulator > observed_vg_per_gene[:, None], axis=1)
    rank_percentile = counts_greater / float(cfg.n_iterations)

    # Build result list
    results: List[GenePermutationResult] = []
    for idx, gene in enumerate(unique_genes):
        results.append(
            GenePermutationResult(
                gene_id=str(gene),
                source=source_name,
                observed_vg=float(observed_vg_per_gene[idx]),
                shuffled_mean_vg=float(shuffled_mean_vg[idx]),
                rank_percentile=float(rank_percentile[idx]),
                n_iterations=cfg.n_iterations,
            )
        )

    return results


# -----------------------------
# Top-level orchestrator
# -----------------------------
def run_global_permutation_test(
    source_to_paths: Dict[str, Dict[str, str]],
    cfg: PermutationConfig,
) -> pl.DataFrame:
    """
    Run permutation test for multiple sources. The `source_to_paths` mapping should be:
      {
        "clingen": {
            "observed_variants": "/path/to/clingen_observed.parquet",
            "null_variants": "/path/to/clingen_null.parquet",
            "af_pool": "/path/to/gnomad_clingen_afs.parquet"  # optional per-source override
        },
        "background": { ... }
      }

    Per your instruction, ClinGen AFs will be used to permute onto Clingen_NULL, and
    Background AFs onto Background_NULL. If a source has no per-source 'af_pool' provided,
    the top-level cfg.af_pool_path will be used as fallback.
    """

    all_results: List[GenePermutationResult] = []

    for source_name, paths in source_to_paths.items():
        # Expected keys in paths: 'observed_variants', 'null_variants', optional 'af_pool'
        if "null_variants" not in paths:
            raise ValueError(f"'null_variants' path is required for source {source_name}")
        if "af_pool" in paths:
            af_pool_path = paths["af_pool"]
        else:
            af_pool_path = cfg.af_pool_path

        # load AF pool for this source
        logging.info("Loading AF pool for source %s from %s", source_name, af_pool_path)
        af_pool = load_af_pool(af_pool_path)

        # Use the null variants file for permutations (your requested mapping)
        null_variants_path = paths["null_variants"]
        logging.info("Running permutations for source %s with null variants %s", source_name, null_variants_path)

        results = run_permutations_for_source(
            source_name=source_name,
            variants_path=null_variants_path,
            af_pool=af_pool,
            cfg=cfg,
        )
        all_results.extend(results)

    # Convert results into a polars DataFrame and write out
    df = pl.from_records(all_results)
    # persist
    out_path = cfg.out_path
    df.write_parquet(out_path)
    logging.info("Wrote permutation results to %s", out_path)
    return df


# -----------------------------
# Example main() usage
# -----------------------------
def main() -> None:
    logging.basicConfig(level=logging.INFO, format="%(asctime)s %(levelname)s %(message)s")

    cfg = PermutationConfig(
        n_iterations=100,
        seed=42,
        af_pool_path="path/to/global_gnomad_observed.parquet",  # fallback pool
        out_path="permutation_vg_results.parquet",
        log_every=10
    )

    # Per your explicit mapping:
    # - ClinGen AFs -> permute onto Clingen_NULL
    # - Background AFs -> permute onto Background_NULL
    # Adapt these paths to your environment.
    SOURCES = {
        "clingen": {
            # observed_variants not strictly used here for permutations but could be kept
            "observed_variants": "path/to/clingen_observed.parquet",
            "null_variants": "path/to/clingen_null.parquet",
            "af_pool": "path/to/gnomad_clingen_afs.parquet",  # use ClinGen-specific afs pool
        },
        "background": {
            "observed_variants": "path/to/background_observed.parquet",
            "null_variants": "path/to/background_null.parquet",
            "af_pool": "path/to/gnomad_background_afs.parquet",  # background-specific afs pool
        },
    }

    # Run
    df = run_global_permutation_test(SOURCES, cfg)
    # Print top constrained genes (rank close to 0)
    top = df.sort("rank_percentile").head(20)
    print(top)

if __name__ == "__main__":
    main()
